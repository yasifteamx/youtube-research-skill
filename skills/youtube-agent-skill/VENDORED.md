# Vendored: youtube-agent-skill

- **Source:** https://github.com/jakeschincariol/youtube-agent-skill — by Jake Schincariol.
- **Licence:** MIT — Copyright (c) 2026 Jake Schincariol. Original `LICENSE` file kept in this folder.
- **What it is:** 11 free, no-signup, no-API-key YouTube sub-skills in `skills/`: yt-script (21 hook formulas, hook scoring), yt-package (title + thumbnail as one pairing), yt-viral, yt-retention (reads retention exports, tells you the exact second people left), yt-shorts, yt-edit (transcript → edit decision list), yt-seo, yt-chapters, yt-comment, yt-plan, yt-audit. Plus 6 Python tools, all compile-checked, and a voice-profile template at `templates/voice.md`.
- **Kept/changed:** vendored unchanged (no `.git` was present in the local copy).
- **How we use it in this repo:** yt-script for scripts and hook scoring, yt-package for title/thumbnail pairing, yt-retention for post-publish analysis, yt-shorts for the Shorts funnel. See the root `SKILL.md`.
